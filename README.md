# BRACE-KV: Risk-Controlled Budget Selection for KV-Cache Compression

Code and data for the paper by Hyunjin Yi, Oteo Mamo, Olga Kogiou, Guang Wang, and Weikuan Yu, Findings of the Association for Computational Linguistics: EACL 2027.

Download `brace-kv-code.tgz` and `brace-kv-data.tgz` from the [Releases](../../releases) page, extract both into the same directory, and follow `brace-kv-code/README.md`. The CPU reproduction regenerates every table and figure in the paper from the stored results without a GPU. `SHA256SUMS` lists checksums for both archives.
